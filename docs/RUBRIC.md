# Оценка готовности бизнес-задачи

Цель рейтинга — показать, сколько уточнений понадобится студенческой команде до начала работы. Это не оценка бренда компании или ценности идеи. Формула и веса взяты из кейса AI Sana; качественные уровни ниже — наше правило реализации.

| Уровень | Значение |
|---|---|
| 0 | Сведения нет. |
| 1 | Есть общая фраза; команда вынуждена угадывать. |
| 2 | Предмет назван, но не хватает деталей для начала. |
| 3 | Работу можно начать; осталось одно существенное уточнение. |
| 4 | Есть конкретные факты и проверяемые условия по критерию. |

Итог = сумма `округление(вес × уровень / 4)` для подтверждённых человеком полей. Неподтверждённое или пустое поле получает 0. Весовые критерии: контекст и потребность 20; данные и материалы 20; ожидаемый результат 15; критерии успеха 15; ограничения 10; пользователи 10; контакт 5; формат взаимодействия 5. Максимум 100.

AI должен вернуть по каждому критерию: уровень, короткую дословную цитату из соответствующего поля, причину именно этого уровня и одно следующее действие. Цитата программно проверяется по исходному тексту. Если AI недоступен или цитата отсутствует, применяется подписанная консервативная локальная оценка. Пустое поле и неподтверждённый текст не дают баллов даже при высоком уровне AI.

Дополнительные правила уровня 4:

- Контекст: описаны текущая ситуация и желаемое изменение.
- Данные: источник, формат или пример и способ доступа.
- Результат: конкретный передаваемый артефакт и его границы.
- Успех: измерение, порог и способ проверки.
- Пользователи: конкретный сегмент и его задача.
- Формат взаимодействия: канал и частота обратной связи.
