## Что остаётся неправильным

1. Существующий документ может попасть не в то поле; точная цитата не гарантирует полный и полезный бриф.
2. Доступ к данным после срока проекта не обнулил оценку данных. Предупреждения недостаточно, если баллы вводят в заблуждение.
3. В объяснениях полных русской и казахской карточек встречалось утверждение, что способ передачи материалов не указан, хотя пользователь написал про электронную почту. В английской карточке формат результата считался неуказанным при явных PDF и CSV.
4. Некоторые уточнения касаются необязательных деталей, а не препятствия к началу работы. Полезность всех вопросов и объективность уровней не гарантированы.

Ручные наблюдения не отменяются успешными структурными тестами. Следующий приоритет — калибровка оценок и объяснений на новых черновиках.

## Механизм и границы проверки

Модель выбирает инструменты рубрики, проверки источников, расчёта и сравнения изменений. Python собирает поля по указанным фрагментам ввода; явные ответы, включая очистку поля, имеют приоритет. Отдельный AI-аудит оценивает покрытие оригинального источника. Финальный валидатор проверяет структуру, источники, семь критериев, уровни, вопросы и допустимость положительной оценки. Нецелевой ввод и критерии с недопустимым статусом получают ноль.

Это снижает риск выдуманных фактов и неверной арифметики, но семантический аудит тоже использует AI и может ошибаться. Баллы до подтверждения человеком предварительные. Ошибка API не подменяется шаблоном: локальная проверка запускается явно и подписана.

## Как повторить

Используйте интерпретатор виртуального окружения из README; ниже `python` означает именно его. Ключ и модель задаются через локальный `.env`; ключ нельзя передавать в командной строке или коммитить.

```text
python -m pytest tests/test_architect.py -q
python scripts/evaluate_architect.py
python scripts/evaluate_workflows.py
python scripts/evaluate_workflows.py --live
python scripts/evaluate_architect.py --live --case library_ru --with-answers
```

Без `--live` проверяется явный офлайн-режим, не качество AI. `evaluate_workflows.py --live` запускает шесть платных анализов; задержки и баллы могут отличаться. Нужен ручной просмотр вопросов и объяснений.

Первичные локальные отчёты: `.qa/final-live-workflows-v2.json` и `.qa/final-adversarial-v2/results.json`. `.qa/` намеренно не включена в Git. Дополнительные сложные примеры — исследовательский локальный прогон; повторяемые сдаваемые наборы находятся в `data/acceptance_cases.json` и `data/evaluation_cases.json`.
