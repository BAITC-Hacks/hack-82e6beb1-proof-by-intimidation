# Sana — интерфейс рабочего продукта

## Назначение

Пользователь должен понять следующий шаг, увидеть пользу AI и закончить действие. Главная визуальная особенность — сопоставление текста задачи с конкретными вопросами и объяснением рейтинга.

## Визуальные правила

- Светлая рабочая область, белые поверхности, тёмный читаемый текст и один синий акцент действия.
- Постоянная навигация: каталог, редактор, мои задачи. Одинаковые названия действий на всём пути.
- Одна главная кнопка на текущем этапе. Фильтры и вторичные действия визуально подчинены ей.
- Текст вопросов и карточек — основное содержимое; баллы помогают принять решение и не заменяют объяснения.
- Одинаковые отступы, высоты полей, размеры подписей и состояния кнопок.
- Короткие понятные сообщения об ошибках рядом с действием, видимый фокус клавиатуры, нормальный перенос длинных слов.
- Русский, казахский и английский интерфейс; названия задач и пользовательский текст сохраняют исходный язык.
- Нативные элементы управления, проверка на узком экране и ноутбуке; анимация только для обратной связи.
