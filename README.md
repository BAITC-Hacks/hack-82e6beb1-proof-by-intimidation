# AI Sana Challenge Hub

## Краткое описание

AI Sana Challenge Hub превращает краткое описание бизнес-потребности в понятную карточку практической задачи для студенческих команд. Представитель бизнеса вручную подтверждает карточку, публикует её в каталоге и сам принимает или отклоняет отклики команд.

## Что реализовано

- AI-анализ черновика с видимым журналом инструментов и минимум тремя уточняющими вопросами.
- Редактируемая карточка с обязательными полями и ручным подтверждением до публикации.
- Прозрачный рейтинг готовности 0–100: качество каждого поля 0–4, цитата из ввода, причина балла и следующий шаг. Баллы только за подтверждённые человеком поля; пересчёт после уточнения опубликованной задачи.
- Общий каталог всех опубликованных задач: сортировка по рейтингу, фильтры по теме и уровню готовности.
- Неограниченная отправка откликов: идея, план, срок и ссылка на прототип.
- Ручной выбор или отклонение предложений бизнесом; начисление 10 демонстрационных баллов после подтверждения прогресса.
- Локальные синтетические данные: 5 черновиков, 5 карточек, 5 команд и 5 откликов.

## Как работает решение

1. Бизнес вводит слабый черновик задачи.
2. Агент анализирует недостающие сведения и предлагает уточняющие вопросы.
3. Из черновика и ответов создаётся редактируемая карточка без добавления новых фактов.
4. Бизнес подтверждает поля, видит рейтинг и публикует задачу.
5. Студенческая команда находит задачу в каталоге и отправляет предложение.
6. Бизнес вручную принимает или отклоняет предложение и подтверждает прогресс выбранной команды.

### Соответствие требованиям кейса

| Требование | Как выполнено | Где в коде | Как проверить |
|---|---|---|---|
| 3+ уточняющих вопроса | Анализ пропусков и до 5 вопросов | `agent/tools.py` | Ввести слабый черновик |
| Редактируемая карточка и подтверждение | Все 10 полей доступны до публикации; есть checkbox подтверждения | `app.py` | «Создать задачу» |
| Рейтинг 0–100 | Взвешенные уровни 0–4, дословные основания AI, локальная проверка цитат | `rating.py`, `agent/review.py`, `docs/RUBRIC.md` | Сравнить слабый и подробный brief; раскрыть «Почему такой рейтинг» |
| Каталог для всех, сортировка, фильтры | Все `published` задачи сортируются по score | `app.py` | «Каталог» |
| Отклик команды | Форма идеи, плана, срока и ссылки сохраняется локально | `app.py`, `storage.py` | Открыть карточку и отправить форму |
| Ручной выбор бизнеса | Кнопки «Выбрать команду» и «Отклонить» | `app.py` | «Отклики и выбор» |
| AI без выдумывания фактов | Модель выбирает инструменты; карточка строится только из ввода | `agent/core.py`, `agent/tools.py` | Посмотреть журнал шагов |

### Как работает AI-агент

`agent/core.py` запускает реальный многократный цикл OpenAI Responses API: модель сама выбирает до четырёх инструментов и максимум шести шагов. В интерфейсе показываются имя инструмента и короткий JSON-результат.

- `analyze_draft(draft)` — ищет недостающие поля.
- `propose_questions(missing_fields)` — формирует уточняющие вопросы.
- `build_card(draft, answers)` — создаёт карточку только из предоставленных фактов.
- `score_card(card)` — рассчитывает рейтинг.

Системный промпт расположен в `agent/prompts.py`. При отсутствующем ключе, ошибке API или некорректном ответе интерфейс явно показывает офлайн-режим; он использует локальные правила, а не выдаёт результат за AI.

Отдельный AI-review оценивает каждый из восьми критериев по уровням 0–4, объясняет оценку и предлагает одно конкретное исправление. Его цитата проверяется программно: выдуманные факты не влияют на баллы. Формальные ограничения не позволяют поставить максимум, например, данным без способа доступа или метрике без порога. При ошибке review используется локальная консервативная оценка с явной подписью. Формула и уровни — в [`docs/RUBRIC.md`](docs/RUBRIC.md).

## Технологии

- Python 3.11+
- Streamlit 1.49.1
- OpenAI Python SDK 1.107.2, Responses API
- python-dotenv 1.1.1
- pytest 8.4.2
- Локальное JSON-хранилище; внешняя база данных пока не нужна.

## Архитектура проекта

```text
app.py (Streamlit)
  ├── agent/core.py → OpenAI tool-calling loop
  │     ├── agent/prompts.py
  │     ├── agent/tools.py → анализ, вопросы, карточка, рейтинг
  │     └── agent/review.py → оценка качества и проверка цитат
  ├── rating.py → прозрачная формула 0–100
  └── storage.py → data/*.json и data/runtime.json
```

## Установка и запуск

Требуется Python 3.11 или новее.

### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# Укажите OPENAI_API_KEY и OPENAI_MODEL в .env
python -m streamlit run app.py
```

### Linux/macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
# Укажите OPENAI_API_KEY и OPENAI_MODEL в .env
python -m streamlit run app.py
```

| Переменная | Назначение | Пример | Обязательна |
|---|---|---|---|
| `OPENAI_API_KEY` | Ключ OpenAI API | `sk-...` | Для AI-режима; без него доступен явно помеченный офлайн-режим |
| `OPENAI_MODEL` | Модель OpenAI | `gpt-4.1-mini` | Для AI-режима |

## Как проверить решение

1. В разделе «Создать задачу» выберите любой из пяти черновиков через «Быстрый старт» (первый уже выбран) и нажмите «Проверить черновик». Посмотрите предварительные уровни и дословные основания.
2. Ответьте на уточняющие вопросы в полях карточки — либо включите «Подставить синтетические ответы для демонстрации», чтобы пройти сценарий без набора текста. Подставленные сведения остаются редактируемыми и не являются ответом AI.
3. Подтвердите карточку и опубликуйте её. Рейтинг должен вырасти, а задача появится в разделе «Каталог».
4. В «Каталоге» отправьте предложение от любой команды.
5. В разделе «Отклики и выбор» выберите или отклоните это предложение вручную. Уточните опубликованную задачу там же и проверьте пересчёт рейтинга.

### Обработка ошибок и безопасность

- Пустой или слишком длинный черновик не отправляется на анализ.
- Неполное предложение команды не сохраняется.
- Сбой API переводит сценарий в явно подписанный офлайн-режим.
- `.env` игнорируется Git; ключи не записываются в исходный код или JSON-данные.

### Тесты

```bash
python -m pytest -q
```

Тесты проверяют, что общая фраза не даёт максимум, подробный brief получает больше, неподтверждённые поля дают 0, выдуманная AI-цитата не влияет на баллы, а карточка не добавляет факты от себя.
